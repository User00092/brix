Brix accepts plain-language browser tasks through a REST API or CLI. Codex reasons about the task
while Brix owns deterministic Playwright actions, persistent profiles, permissions, events,
artifacts, and human-control handoff.

## What Brix provides

- Isolated Chromium browser sessions with reusable profiles
- Structured task status and results
- Live task events over WebSocket
- Pause, resume, cancel, and user-control endpoints
- Challenge detection that pauses for CAPTCHA, MFA, and passkeys
- A dashboard for creating tasks and observing browser activity
