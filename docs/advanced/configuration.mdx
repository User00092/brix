---
title: "Configuration"
description: "Brix environment variables and local data"
---

| Variable | Default | Purpose |
| --- | --- | --- |
| `BRIX_DATA_DIR` | `.brix` | SQLite, profiles, task runs, and artifacts |
| `BRIX_DATABASE` | `$BRIX_DATA_DIR/brix.db` | Override the SQLite database path |
| `BRIX_CODEX_EXECUTABLE` | `codex` | Codex CLI executable |
| `BRIX_MAX_BROWSER_WORKERS` | `2` | Maximum concurrent browser workers |
| `BRIX_API_TOKEN` | unset | Bearer token required by API and dashboard requests |
| `BRIX_API_URL` | `http://127.0.0.1:8787` | Server used by CLI API commands |
| `BRIX_SECRET_KEY` | development value | Signs short-lived remote-browser access tokens |
| `BRIX_NOVNC_INTERNAL_URL` | unset | Internal authenticated noVNC gateway |

For any non-local deployment, set long random values for `BRIX_API_TOKEN` and `BRIX_SECRET_KEY`.
Keep the noVNC service internal. The `.brix/` directory contains browser authentication material and
must not be committed, shared, or exposed through logs.
