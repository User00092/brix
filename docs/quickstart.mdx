## Prerequisites

Install Python 3.12+, `uv`, and an authenticated Codex CLI.

```bash
uv sync
uv run playwright install chromium
export BRIX_API_TOKEN="replace-with-a-long-random-token"
uv run brix serve
```

Open `http://127.0.0.1:8787`, or submit a task from another shell:

```bash
export BRIX_API_TOKEN="replace-with-a-long-random-token"
uv run brix task "Open example.com and report the page title"
```

The command returns a task ID. Inspect it with `uv run brix status <task-id>`. When a task requires
CAPTCHA, MFA, or another human step, open its live browser, complete the step, and return control to
the agent. Brix preserves the browser profile and Codex task context.
