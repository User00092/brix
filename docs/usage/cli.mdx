---
title: "CLI"
description: "Serve Brix and call its task API"
---

```bash
brix --version
brix serve [--host 127.0.0.1] [--port 8787] [--reload]
brix task "<instruction>" [--profile default]
brix status <task-id>
```

`serve` starts the API and dashboard. `task` and `status` call the configured server and print JSON.
They read `BRIX_API_URL` (default `http://127.0.0.1:8787`) and `BRIX_API_TOKEN`.

```bash
export BRIX_API_URL="https://brix.example"
export BRIX_API_TOKEN="..."
brix task "Download my latest invoice" --profile work
```

The task API may require approval or human control before actions with external side effects. A task
request never grants permission to bypass CAPTCHA or other human-verification challenges.
